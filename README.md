# HornHubb

Магазин HORN HUB — Telegram Mini App (статический сайт: `index.html`, `css/style.css`, `js/app.js`).

## Цены и наличие через Google-таблицу (рекомендуется)

Товары, цены, наличие и районы можно вести в Google-таблице — сайт сам подхватывает изменения, код трогать не нужно.

### Подключение (один раз)

1. **Скачайте шаблон** — файл [`catalog-template.csv`](catalog-template.csv) (на GitHub: открыть файл → кнопка «Download raw file»).
   В нём уже все текущие товары, цены, цены по районам, наличие и фото.
2. **Создайте таблицу**: [Google Таблицы](https://sheets.new) → *Файл → Импорт → Загрузка* → выберите файл →
   «Заменить текущий лист» → «Импортировать данные».
3. **Галочки вместо TRUE/FALSE** (удобнее): выделите колонки «В наличии» и «Показывать» → *Вставка → Флажок*.
4. **Опубликуйте таблицу**: *Файл → Поделиться → Опубликовать в интернете* → выберите лист →
   формат «Файл CSV» → «Опубликовать» → скопируйте ссылку.
5. **Вставьте ссылку** в начало `js/app.js`: `const SHEET_URL = 'ссылка';`
   (на GitHub: открыть файл → карандаш → вставить → «Commit changes»). Или просто пришлите ссылку разработчику.
6. **Проверка**: внизу сайта появится строка «Цены обновлены: …» — значит, таблица подключена.

### Как пользоваться

| Колонка | Что делает |
|---|---|
| `id` | Служебный номер, **не меняйте**. Для нового товара оставьте пустым. |
| `Бренд`, `Вкус` | Как товар называется на сайте и в заказе. |
| `Категория` | Жидкости / Одноразки / Pod-системы / Картриджи. |
| `Цена` | Старая (зачёркнутая) цена в злотых. |
| `Цена со скидкой` | Цена для всех районов. Пусто — скидки нет. |
| `Цена Bemowo`, `Цена Ożarów`, … | Цена в конкретном районе (если пусто — берётся «Цена со скидкой»). |
| `В наличии` | Галочка снята — «Нет в наличии», товар уходит вниз. |
| `Показывать` | Галочка снята — товар скрыт с сайта (строку удалять не нужно). |
| `Фото` | Путь в папке `images` (`elf/Spearmint.png`), ссылка на картинку или ссылка на файл в Google Диске (доступ «Все, у кого есть ссылка»). Пусто — фото ищется по названию в папке бренда. |

- **Новый товар** — новая строка (id пустой). Порядок строк = порядок товаров на сайте.
- **Новый район** — новая колонка `Цена <район>`, например `Цена Wola`: район сам появится в окне выбора, меню и корзине.
- **Когда видно изменения**: Google обновляет опубликованную таблицу примерно за 5 минут; покупатель увидит новые цены
  при следующем открытии магазина.
- **Если таблица недоступна** (нет интернета, закрыт доступ, ошибка) — сайт покажет последнюю загруженную версию.
  Строки без названия или цены пропускаются, остальное работает.
- Пока таблица подключена, правки `CATALOG` в `js/app.js` на сайт не влияют — это запасной каталог на крайний случай.

## Защита бота: подписчики, удаление спама, сторож

Если кто-то получит токен бота, он может рассылать от его имени что угодно. Чтобы в таком случае
**удалить спам у всех** и **сделать свою рассылку**, нужен список подписчиков — его собирает скрипт
в вашей Google-таблице (бесплатно, без отдельного сервера). Там же — сторож, который пишет на почту,
если с ботом что-то не так.

### Сразу
1. **Смените токен**: @BotFather → `/mybots` → бот → *API Token* → *Revoke current token*.
   Старый перестанет работать. Магазин и кнопка «Открыть магазин» продолжат работать.
2. **Защитите Telegram**: Настройки → Конфиденциальность → *Облачный пароль* (включить).
3. **Никому не отправляйте токен**, не вставляйте его на сайты и в боты, не храните в GitHub.

### Подключение скрипта (один раз)
1. Откройте Google-таблицу (можно ту же, что для каталога) → *Расширения → Apps Script*.
2. Удалите всё в редакторе и вставьте целиком файл [`bot/hornhub-bot.gs`](bot/hornhub-bot.gs)
   (на GitHub: открыть файл → *Raw* → выделить всё → скопировать). Нажмите 💾.
3. ⚙️ *Настройки проекта → Свойства скрипта → Добавить свойство*: `BOT_TOKEN` = **новый** токен из @BotFather.
4. *Развернуть → Новое развертывание* → тип «Веб-приложение» → «Запуск от имени: Я», «Доступ: Все» →
   *Развернуть* → разрешите доступ → скопируйте **URL веб-приложения**.
5. Вставьте этот URL в начало `js/app.js`: `const SUBSCRIBERS_URL = 'ссылка';` (или пришлите разработчику).
6. Обновите страницу таблицы → появится меню **HORN HUB** → *Включить сторожа бота*.

Подписчики попадают на лист «Подписчики», когда открывают магазин или пишут боту /start.
Подпись Telegram проверяется — подделать список нельзя.

### Если снова пришёл спам от имени бота
1. Смените токен в @BotFather и вставьте новый в `BOT_TOKEN` (п. 3 выше).
2. Меню **HORN HUB → 🧹 Удалить спам у всех** → при желании напишите текст, который останется в чате
   (например: «Это были мошенники, мы удалили их сообщение»).

Telegram позволяет удалять сообщения **не старше 48 часов** — действуйте сразу. Удаляются сообщения
в чате с ботом за последние двое суток у всех из списка.

### Другие пункты меню
- **📣 Разослать сообщение всем** — своя рассылка подписчикам (акции, новости).
- **🛡 Включить сторожа бота** — раз в час проверяет бота и пишет на почту, если бота подключили к чужому
  серверу или поменяли его имя/описание, а также пополняет список подписчиков.
- **ℹ️ Проверить бота** — работает ли токен, сколько подписчиков, есть ли тревоги.

## Как обновлять каталог в коде (если таблица не подключена)

Всё редактируется в начале файла `js/app.js`, в массиве `CATALOG`:

- **Цены** — `price` (старая цена) и `sale` (цена со скидкой), в злотых. Нет скидки — не указывайте `sale`.
- **Цена по районам** — вместо числа укажите `sale` для каждого района: `sale: { 'Bemowo': 40, 'Ożarów': 50 }`.
  Названия районов пишите точно как в `DISTRICTS`. Если для района цена не указана, берётся цена первого района
  из списка `DISTRICTS`. Сейчас так сделано для жидкостей.
- **Новый вкус** — допишите название **в конец** списка `flavors` и загрузите картинку в `images/<folder>/`.
  Имя файла = название, где всё кроме латиницы и цифр заменено на `_`:
  `P&B Cloud` → `P_B_Cloud.png`, `Love 777` → `Love_777.png`.
- **Закончился вкус** — добавьте его название в `soldOut` этого бренда. Товар уйдёт вниз списка с пометкой «Нет в наличии».
- Порядок вкусов не меняйте — от него зависят id товаров (по ним у покупателей хранятся корзина и избранное).
- Категория товара — поле `category`: `liquid` (жидкости), `disposable` (одноразки), `pod` (Pod-системы), `cartridge` (картриджи).
- Ник консультанта — константа `ADMIN_NICK`, курсы валют — `CURRENCIES`.
- Районы — массив `DISTRICTS`, новый район просто допишите в список. Окно выбора района показывается
  при первом входе на сайт, дальше район запоминается (от района зависят цены). Сменить район можно в меню или в корзине
  при оформлении — цены сразу пересчитываются. Район попадает в текст заказа.

## Закрыть магазин на техобслуживание

Сейчас магазин **закрыт**: при открытии покупатель видит только экран «Магазин на техническом обслуживании»
(на русском, украинском или английском — по языку покупателя). Каталог, корзина, меню и заказ недоступны.

- Включается одним словом в начале `index.html`: `<html lang="ru" data-theme="halloween" data-maintenance>`.
- **Открыть магазин** — удалите ` data-maintenance` (останется `<html lang="ru" data-theme="halloween">`).
  На GitHub: открыть `index.html` → карандаш → удалить слово → «Commit changes». Через несколько минут магазин снова работает.
- Корзина и избранное покупателей за это время не пропадают.
- Подписчики бота продолжают собираться и во время техобслуживания.
- Тексты экрана — в `js/app.js`, ключи `maintTitle`, `maintText`, `maintStatus` в переводах.

## Оформление (сезонная тема)

Сейчас включена тема **«Хэллоуин»**: оранжево-фиолетовые цвета, баннер `images/banner_halloween.webp`,
летучие мыши, паук на паутинке, искры от фонарей и мерцающая тыква на баннере,
паутина на фоне и в окне выбора района.

- Включается одной строкой в начале `index.html`: `<html lang="ru" data-theme="halloween">`.
- Чтобы вернуть обычный вид — уберите `data-theme="halloween"` (останется `<html lang="ru">`):
  вернутся фиолетовые цвета и старый баннер `images/banner.png`.
- Цвета и баннер темы — в начале `css/style.css`, блок `:root[data-theme="halloween"]`.

## Таймер акции

Под баннером — таймер распродажи. Сейчас: **31 октября — 1 ноября** (время по Варшаве).
До начала показывает «До старта», во время акции — «Распродажа идёт! До конца», после окончания исчезает сам.

- Даты — в начале `js/app.js`, константа `SALE` (`start` — начало, `end` — момент окончания).
- Название акции в таймере — там же, `title` (на русском, украинском и английском).
- Цены на время акции — там же, `prices`: сейчас **все жидкости по 30 zł во всех районах**.
  Цены включаются ровно в момент старта и сами возвращаются после окончания (работает и с Google-таблицей).
- Убрать таймер совсем: `const SALE = null;`

## Обновление сайта и кэш Telegram

В `index.html` файлы подключены с версией: `css/style.css?v=…` и `js/app.js?v=…`.
Если меняете **одновременно** `index.html` и `js/app.js`/`css/style.css` — поменяйте и `v=` (например, на сегодняшнюю дату),
иначе Telegram может показать новую страницу со старым скриптом из кэша. Для обычных правок цен и наличия в `app.js` это не нужно.

## Как работает заказ

Покупатель собирает корзину → «Оформить заказ» → «Отправить в Telegram».
Текст заказа копируется в буфер и открывается чат с консультантом (текст по возможности подставляется в поле сообщения).
