# Носорог в живом свете (тема «Black Friday»)

В шапке магазина — носорог со спины на глянцевом полу; позади него крупная надпись BLACK FRIDAY.
Свет «живой»: прожекторы включаются по очереди, потом свет медленно ходит по дуге за спиной.
Пальцем свет можно вести, нажатие — вспышка (на миг виден весь носорог).

**Как это сделано.** Носорог отрендерен в Blender (Cycles) в полном качестве — с настоящими материалами
ткани и кожи, тенями и отражением в полу. Каждый источник света отрендерен **отдельным чёрно-белым слоем**:
семь прожекторов по дуге за спиной (`arc0` … `arc6`, слева направо), мягкий свет спереди (`key`) и луч сверху
(`top`). На сайте слои складываются на холсте с разным весом (`js/app.js`, раздел «Black Friday: живой свет») —
так свет двигается, а картинка остаётся фотографического качества. Слой `matte` — силуэт: по нему фигура
перекрывает надпись позади. `poster.webp` — готовая картинка: для «уменьшить движение» и если слои не загрузились.

**Лицо не показываем:** камера сзади, под углом 12°. Проверка — `render.py mask`: глаза и ноздри должны дать
0 пикселей (при угле больше 14° появляются первые пиксели, поэтому камеру дальше не поворачиваем).

| Файл | Что это |
|---|---|
| `tools/globe/rhino.blend` | исходная модель из Blender |
| `tools/blackfriday/render.py` | сцена (камера, пол, свет) и рендер слоёв |
| `tools/blackfriday/post.py` | сборка слоёв в картинки для сайта |
| `images/blackfriday/*.webp` | слои света, силуэт и готовая картинка — их грузит сайт |

## Перерисовать (после правок модели или света)

```sh
pip install bpy==5.2.3 numpy pillow
python tools/blackfriday/render.py mask   tools/globe/rhino.blend /tmp/bf_mask   # лицо: должно быть 0 пикселей
python tools/blackfriday/render.py passes tools/globe/rhino.blend /tmp/bf_out    # ~10 минут на 4 ядрах
python tools/blackfriday/post.py /tmp/bf_out images/blackfriday
```

Размер и качество — переменные `RES` (ширина, сейчас 960) и `SPP` (сэмплы, сейчас 192) у `render.py`;
яркость слоёв — `GAIN` у `post.py` (например `GAIN=arc2=1.5,top=0.8`).
После пересборки поменяйте `?v=` в `index.html`, чтобы Telegram не взял старые файлы из кэша.
